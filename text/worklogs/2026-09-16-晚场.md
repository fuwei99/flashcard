# 2026-09-16 晚场 · 补上「AI 插手闭环」缺的 20%

## 背景

盘点「个人使用 / AI 随时插入卡、改样式、改流程」的便捷性后，确认骨架
（公共目录即接口 / 分片书 / 模板热重载 / workflow 即文件 / 原子写）已经
到位，但闭环缺四环：status.json 没通电、写后不自动生效、词条非一级公民、
写无校验。

本场先补**前两环**（第三、四环是独立大改，另开）。

## 做了什么

### 1. status.json 落地（`StatusWriter`）

- 新增 `app/lib/services/status_writer.dart`。
- 在 `_Bootstrap._boot()` 里 init（拿 settings / store / loadBooks），
  首帧后写第一份。
- 触发点：**启动 / 背完一张（限流 15s）/ 进后台 / 退出会话**。
- 内容：`format=flashcard.status.v1`、today（word/card done + limit +
  review_limit）、streak、累计、`totals`（books/cards/learned/fresh/due/
  mastered）、每本书一行进度。
- 只写不读，写失败静默；落在 `<公共目录>/Flashcard/status.json`。
- 书进度走 `allCardIds`（index.json 种子 id，不触发章节读盘），与首页同口径。

### 2. 自动热重载（`HotReload`）

- 新增 `app/lib/services/hot_reload.dart`：walk `templates/` + `books/`，
  取「文件数 + 最大 mtime」当指纹。
- `MainScaffold` 改 `with WidgetsBindingObserver`：
  - `paused` → 写 status 快照；
  - `resumed` → `HotReload.changed()` 为真则重读模板 + 刷新四个 Tab +
    弹「已自动重载」。
- 首次进前台只 `resync()` 建基线，不误报。
- AI 往公共目录丢书 / 改 CSS 后，用户切回 App 即生效，不用再手点。

## 没做（另开）

- 词条一级公民（`LemmaStore`，word 主键 + 跨书共享 + id 稳定）——大重构，
  需要先有测试兜底。
- 写入 schema 校验 / 回执——先靠「宽容读」兜，后面单做。

## 影响面

- 新增 2 个服务文件；改 `main.dart` / `main_scaffold.dart` /
  `review_screen.dart` 接线；`WORKFLOW.md` §8 同步。
- 不动 FSRS、不动模板渲染、不动存储格式，向后兼容。
