# 2026-09-16 晚场 · 补上「AI 插手闭环」缺的 20%

## 背景

盘点「个人使用 / AI 随时插入卡、改样式、改流程」的便捷性后，确认骨架
（公共目录即接口 / 分片书 / 模板热重载 / workflow 即文件 / 原子写）已经
到位，但闭环缺四环：status.json 没通电、写后不自动生效、词条非一级公民、
写无校验。

本场先补**前两环**（第三、四环是独立大改，另开）。

## 做了什么

### 1. status.json 落地（`StatusWriter`）

- 新增 `app/lib/services/status_writer.dart`。
- 在 `_Bootstrap._boot()` 里 init（拿 settings / store / loadBooks），
  首帧后写第一份。
- 触发点：**启动 / 背完一张（限流 15s）/ 进后台 / 退出会话**。
- 内容：`format=flashcard.status.v1`、today（word/card done + limit +
  review_limit）、streak、累计、`totals`（books/cards/learned/fresh/due/
  mastered）、每本书一行进度。
- 只写不读，写失败静默；落在 `<公共目录>/Flashcard/status.json`。
- 书进度走 `allCardIds`（index.json 种子 id，不触发章节读盘），与首页同口径。

### 2. 自动热重载（`HotReload`）

- 新增 `app/lib/services/hot_reload.dart`：walk `templates/` + `books/`，
  取「文件数 + 最大 mtime」当指纹。
- `MainScaffold` 改 `with WidgetsBindingObserver`：
  - `paused` → 写 status 快照；
  - `resumed` → `HotReload.changed()` 为真则重读模板 + 刷新四个 Tab +
    弹「已自动重载」。
- 首次进前台只 `resync()` 建基线，不误报。
- AI 往公共目录丢书 / 改 CSS 后，用户切回 App 即生效，不用再手点。

## 没做（另开）

- 词条一级公民（`LemmaStore`，word 主键 + 跨书共享 + id 稳定）——大重构，
  需要先有测试兜底。
- 写入 schema 校验 / 回执——先靠「宽容读」兜，后面单做。

## 影响面

- 新增 2 个服务文件；改 `main.dart` / `main_scaffold.dart` /
  `review_screen.dart` 接线；`WORKFLOW.md` §8 同步。
- 不动 FSRS、不动模板渲染、不动存储格式，向后兼容。

## 追加（同日稍后）· 补「原子能力」四接口

### 背景

盘点「workflow.js 到底管不管全局」时确认：它只接管了拼写轮，全局会话状态机
仍在 Dart `StudySession`。要让它有一天能自己开车，壳得先给它**读队列 / 取内容 /
交评级**的能力 —— 否则它连「下一张出什么卡」都问不出来。

### 做了什么

1. 新增 `app/lib/services/card_source.dart`：
   - `CardSource` 抽象 + `BookCardSource` 实现，把「卡片状态」（`CardStore`）
     和「卡片内容」（`DeckRepository` 的书/章分片）缝在一起；
   - 找卡先看 `Chapter.ids`（**不触发读盘**），命中才读那一章；书列表读一次缓存。
2. `webview_bridge.dart` 的 `_registerCore()` 注册四个原子接口：
   - `card.get({id})` → 单卡完整数据（fields + state + kv，与 mountCard 同形状）
   - `card.due({limit?, bookId?})` → 到期队列（已学+到期，不含新卡），按 due 升序
   - `card.new({limit?, bookId?})` → 新卡队列（未学、未标熟）
   - `review.commit({id, rating})` → 跑 FSRS + 落盘，回新状态（唯一动调度数据的入口）
3. `WebViewBridge` 构造增可选 `cardSource`，缺省 `BookCardSource()`；所有调用点零改动即生效。

### 关键约束（守住 plan §2.3 铁律）

- **队列只读 id 不读盘**：`card.due` / `card.new` 只用 `Book.allCardIds`，
  6500 词列到期也不进内存。
- **FSRS 只有一份**：`review.commit` 内部调 Dart `scheduler.review()`，
  Web 层拿不到算法，杜绝第三份实现。
- **标熟即出队**：两个队列接口都跳过 `store.isKnown(id)`。

### 影响面

- 新增 1 个服务文件；改 `webview_bridge.dart`（+103/-1）；
- 不动既有 RPC、不动模板、不动存储格式，向后兼容；
- `WORKFLOW.md` 新增 §11 同步接口清单。

### 没做（诚实记录）

- **workflow.js 仍未接管全局流程** —— 会话状态机还在 `StudySession`，
  这次只把「油」补上了，车还没换司机。真正搬家是 plan 阶段 4。
- `review.undo` 仍未实现：完整撤销要事件日志（revlog），现在没有。
- 无 Dart SDK，没跑 `flutter analyze`；只做了括号/引号配平的粗检。
