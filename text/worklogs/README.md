# worklogs

开发工作日志。按日期一个文件：`YYYY-MM-DD.md`。

## 写什么

- 干了什么：改动的文件、commit hash、CI run 编号
- **为什么这么改**：决策理由，尤其是推翻过的方案（这个最值钱）
- 遗留了什么

## 不写什么

- 不写起居录、不写学习记录 —— 那是 obsidian 的事，跟项目无关
- 不写流水账，只写有信息量的决策与结果
